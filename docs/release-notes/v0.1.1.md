## TU VPN 0.1.1 – Login geht wieder · login works again

**Wichtig, wenn die Anmeldung mit „Der Server hat unerwartete Session-Daten geliefert“ scheitert:** Der TU-Server liefert seit Oktober 2026 Session-Cookies, die 0.1.0 abgelehnt hat. Mit 0.1.1 klappt der Login wieder. · **If login fails with “The server returned unexpected session data”:** since October 2026 the TU server sends session cookies that 0.1.0 rejected. 0.1.1 fixes this.

```bash
curl -fsSL https://raw.githubusercontent.com/hannokuegler/tu_vpn/main/install.sh | bash
```

### Behoben · Fixed

- 🔑 **Login mit neuem TU-Cookie-Format** – Cookies mit Leerzeichen/Quotes werden akzeptiert (App und Helper). Sie gehen weiterhin nur über eine `0600`-Datei bzw. stdin an openconnect, nie in einen Shell-Befehl · accepts the TU server's new cookie format (spaces/quotes); the cookie still only reaches openconnect via a `0600` file or stdin, never a shell command
- 🟢 **Kein falsches „Verbunden“ mehr** während eines Logins · no more false “Connected” while a login is running
- 💬 **Genauere Fehlermeldung** – nennt, welcher Session-Wert verworfen wurde (nie den Cookie-Inhalt) · the error names which session value was rejected (never the cookie's content)
- 👋 Willkommensdialog erscheint erneut, wenn die App vor der Antwort beendet wurde · welcome dialog shows again if the app quit before it was answered

### Sicherheit · Security

- Einrichtung „Ohne Mac-Passwort“ gehärtet: Homebrew-openconnect läuft als root nie mehr direkt (nur als `nobody`), die Kopie nur in der Sandbox, Arbeitsdateien in `/private/tmp` – danke an [@raphaelloescher](https://github.com/raphaelloescher) · passwordless setup hardened, thanks to @raphaelloescher
- Helper liest von stdin höchstens so viel, wie die Prüfregeln erlauben · helper reads no more from stdin than the validation rules allow
- `install.sh` akzeptiert als `TUVPN_VERSION` nur `latest` oder `vX.Y.Z` · `install.sh` only accepts `latest` or `vX.Y.Z` as `TUVPN_VERSION`

### Hinweis · Note

Wer den Modus **ohne Mac-Passwort** eingerichtet hat: Die App meldet nach dem Update, dass die Einrichtung veraltet ist – einmal neu einrichten (Helper-Version 2). · If you use the **passwordless mode**, the app will ask you to set it up again once after the update (helper version 2).
