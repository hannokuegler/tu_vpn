## TU VPN 0.1.0 – erste öffentliche Version · first public release

Ein Klick in der Menüleiste – und du bist im Netz der TU Wien. · One click in the menu bar – and you're on the TU Wien network.

```bash
curl -fsSL https://raw.githubusercontent.com/hannokuegler/tu_vpn/main/install.sh | bash
```

### Highlights

- 🔌 **Menüleisten-App „TU“** fürs TUvpn auf Basis von openconnect – kein Cisco Secure Client nötig · menu bar app for TUvpn based on openconnect, no Cisco client needed
- 🔑 **MFA nur einmal pro Session** (~5 Tage) – *Trennen* lässt die Session offen · MFA only once per ~5-day session
- 🌍 **Zwei Profile:** *Nur TU* und *Alles getunnelt* (Bibliotheks-Paper) · two profiles: TU only and all traffic
- 💤 **Übersteht Ruhezustand und WLAN-Wechsel** (`--reconnect-timeout 24 h`) · survives sleep and Wi-Fi changes
- 🙅 **Optional ohne Mac-Passwort** – root-eigene, sandboxed Kopie von openconnect + enge sudo-Regel · optional passwordless mode with a root-owned, sandboxed openconnect copy and a narrow sudo rule
- 💬 **Fehlermeldungen mit nächstem Schritt** – Passwort vs. MFA, Session-Limit, kein Netz, openconnect fehlt … · actionable error messages
- 🇦🇹🇬🇧 Deutsch & Englisch · German & English
- 🖥️ Universal (Apple Silicon + Intel), macOS 13+

### Sicherheit · Security

Tunnel-Log und PID-Datei an root-eigenen Orten, Trennen trifft nur den eigenen Prozess, alle Eingaben für root werden validiert, Geheimnisse nie in der Kommandozeile. Gebaut in GitHub Actions mit `SHA256SUMS` und signierter Build-Provenance. → [SECURITY.md](https://github.com/hannokuegler/tu_vpn/blob/main/SECURITY.md)

```bash
gh attestation verify TUvpn-macOS.zip --repo hannokuegler/tu_vpn
```

### Hinweise · Notes
